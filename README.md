# 플레이 (Play) — 9.5.5

글래스 효과 UI와 적응형 레이아웃을 지원하는 안드로이드 비디오 플레이어 앱입니다.
외부 라이브러리 없이 안드로이드 기본 API만으로 작성했으며, 모든 아이콘·그래픽을 직접 그렸습니다.
모바일(바형), 폴더블(접힘·펼침), 태블릿 화면을 모두 지원하며 한국어·영어·일본어를 제공합니다.

## 주요 기능

- **재생 & 화면**: 0.25x~4.0x 배속, 길게 눌러 2.0x 임시 배속, 7종 화면 비율 + 핀치 줌, 화면 자동 회전(센서·영상 비율 맞춤·세로/가로 고정), 펀치홀(DisplayCutout) 안전 여백, A-B 구간 반복, 북마크, 취침 타이머, 스크린샷 저장, PiP(화면 속 화면), 백그라운드 오디오 재생, 화면 잠금
- **제스처**: 좌측 밝기·우측 볼륨 스와이프(설정에서 각각 ON/OFF 가능), 가로 탐색, 좌/우 더블탭 건너뛰기(5/10/15/30초)
- **YouTube 허브 & 플레이어**: 플레이 자체 A/G 글래스 UI에서 YouTube 카테고리(인기 급상승 · 음악 · 게임 · 영화/예고편 · 테크/과학) 탐색 및 검색, YouTube URL 인텐트 직접 재생, 플레이 글래스 컨트롤·배속·댓글/영상 정보 시트 통합, NewPipe(`org.schabi.newpipe`) 연동 지원
- **프로스케일러 어시스트 (NPU 비디오)**: 25종 플래그십 Snapdragon · Dimensity · Exynos · Tensor NPU 감지 및 공식 칩셋 아트워크, 실시간 AGSL 멀티스테이지 초해상도·로컬 콘트라스트·HDR 다이내믹 톤·크로마 디밴딩, 4종 화질 프로파일(시네마 마스터 · 크리스탈 4K · 애니메이션/2D 라인 · 내추럴 필름), 12포인트 실시간 응답 곡선 그래프 및 A/B 원본 비교(Bypass Hold)
- **비트퍼펙트 어시스트 (NPU 오디오) & USB DAC 비트퍼펙트**: 25종 플래그십 NPU 기반 12밴드 고역 하모닉 복원·보컬/대사 클리어·다이내믹 레인지 확장·스테레오 공간감·소프트 리미터(`DynamicsProcessing`), 하모닉 익사이터 3모드(스튜디오 · 크리스탈 · 진공관 웜), 실시간 주파수 응답 그래프 및 A/B 원음 비교(Bypass Hold), Hi-Res 3단계 출력 감지 및 Android 14+ USB DAC 비트퍼펙트 다이렉트 출력
- **자막 & 웹 자막 검색**: SRT · VTT · ASS · SSA · SMI 지원, 웹 자막 검색·다운로드(제목 자동 정리 · 64비트 파일 해시 매칭 · OpenSubtitles/Subdl/직접 URL · ZIP/GZ 자동 압축 해제 및 즉시 적용), 이중 자막, 자막 싱크 미세 조정(±0.1s / ±0.5s / ±2s), 글자 크기·위치·배경 투명도·색상 설정, 대사 목록 탐색
- **AI 자막 자동 생성**: 기기 동영상의 오디오 트랙을 16kHz 모노로 추출해 Google Gemini · OpenAI Whisper · Groq Whisper · 사용자 지정 OpenAI 호환 서버로 SRT 자막을 생성하고 즉시 적용
- **오디오**: 다중 오디오 트랙 선택, 10밴드 이퀄라이저(`DynamicsProcessing`) + 볼륨 부스트(`LoudnessEnhancer`)
- **라이브러리 & 검색**: 이어보기, 폴더별 탐색, 즐겨찾기, 재생목록, 네트워크 스트림(HTTP/HLS), 필터 및 최근 검색
- **UI 스타일 & 테마**: A (글래스) / G (모던 5슬롯 통합 플로팅 독) 스타일, 라이트/다크/시스템 테마, 강조 색상 8종(4×2 링 스와치, 다이내믹 컬러 포함), 글래스 투명도 조절, 스크롤 시 접히는 독과 하단 진행바 내장 미니 플레이어
- **앱 내 업데이트**: 설정 → 플레이 정보 → 업데이트 확인 (GitHub 릴리스 APK 다운로드 및 설치, 하루 1회 자동 확인, 마크다운 릴리스 노트 뷰어)

## 빌드 / 테스트

Gradle 없이 JDK 21 + Android build-tools 35.0.0 + platform android-35 로 빌드합니다.
툴체인 경로는 환경 변수 `PLAY_TOOLCHAIN` 또는 `toolchain.path` 파일 첫 줄에 지정하세요(저장소에 포함되지 않음).
서명 키 `keystore.jks`는 첫 빌드 시 자동 생성되며 저장소에 포함되지 않습니다.

```powershell
.\build.ps1              # → dist\PlayVideo_Android.apk (minSdk 31, targetSdk 35)
.\tests\ui\run.ps1       # Robolectric 네이티브 그래픽 테스트 → tests\ui\output\
```
